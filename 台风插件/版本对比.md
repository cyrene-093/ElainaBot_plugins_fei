# 台风插件 · 版本对比与建议

## 1. 产品定位

```
                    ┌─────────────────┐
   用户查询台风 ──► │  台风合（推荐）   │
                    │ 官网有图 → 官网  │
                    │ 官网无图 → 本地  │
                    └────────┬────────┘
                             │
           ┌─────────────────┴─────────────────┐
           ▼                                   ▼
   ┌───────────────┐                   ┌───────────────┐
   │  台风官网      │                   │  台风本地      │
   │ 只拉官方产品图 │                   │ 只本地画路径图 │
   │ 无图则提示     │                   │ 气泡尖端到点   │
   └───────────────┘                   └───────────────┘
```

- **合**：一条指令覆盖两种配图策略，日常首选。
- **官网**：与中央台发布页一致；适合「必须官方出品」。
- **本地**：可控、可对比；停编历史台风仍能出图。

---

## 2. 指令对照

| 功能 | 合 | 官网 | 本地 |
|------|----|------|------|
| 当前最强 | `台风` | `台风官网` | `台风本地` |
| 活跃/列表 | `台风列表` | `台风官网列表` | `台风本地列表` |
| 按年 | `台风年份 2024` | `台风官网年份 2024` | `台风本地年份 2024` |
| 查详情 | `台风查询 沙德尔` | `台风官网查询 沙德尔` | `台风本地查询 沙德尔` |
| 帮助 | `台风帮助` | `台风官网帮助` | `台风本地帮助` |
| 个人记录 | `我的台风记录` | （无） | `我的台风本地记录` |

## 3. 配图行为差异（重要）

| 场景 | 合 | 官网 | 本地 |
|------|----|------|------|
| 活跃且官网有 TCBU 图 | 官网图 | 官网图 | 本地图 |
| 活跃但官网暂无 | 本地图 | 提示暂无 | 本地图 |
| 停编（如巴威） | 本地图（跳过官网扫描） | 提示停编无图 | 本地图 |
| 二次相同查询 | 缓存加速 | 缓存加速 | 缓存加速 |

---

## 4. 性能与稳定性（均为 v1.0.0）

三版已统一：

| 项 | 说明 |
|----|------|
| HTTP 会话复用 | 减少握手与句柄泄漏风险 |
| 短缓存 | list≈60s，view≈90s；官网索引≈180s，产品图≈300s |
| 匹配收紧 | 避免空英文名、过短数字误命中 |
| 耗时统计 | 含下载/绘图/上传整段 |
| 卸载清理 | `@on_unload` 关闭会话 |

合 / 本地额外：本地 PIL 绘图放到线程池，避免卡住 bot 事件循环。

## 5. 建议部署方案

### 方案 A（推荐）

只部署：

- `台风合.py`

适合生产环境、减少指令认知成本。

### 方案 B（对比调试）

部署：

- `台风合.py`
- `台风官网.py`
- `台风本地.py`

用三套前缀分别看官网原图与本地气泡图差异。

### 方案 C（强制官方）

只部署：

- `台风官网.py`

接受「无官方产品图就不配图」。
