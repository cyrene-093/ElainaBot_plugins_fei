# 台风插件说明

本目录说明 ElainaBot `plugins/alone/` 下三套台风相关插件的**区别、适用场景与建议**。

> **声明**：茉莉奶绿原创 · 飞行漂绒修改优化 · 当前版本均为 **1.0.0（1）**

## 三个版本一览

| 文件 | 版本 | 指令前缀 | 路径图来源 | 推荐度 |
|------|------|----------|------------|--------|
| [`台风合.py`](../../plugins/alone/台风合.py) | **1.0.1** | `台风` / `台风查询`… | **优先官网图**，没有则**本地绘图** | ★★★ 默认推荐 |
| [`台风官网.py`](../../plugins/alone/台风官网.py) | **1.0.0** | `台风官网`… | 仅中央台发布页 TCBU 产品图 | ★★ 只要官网原图时用 |
| [`台风本地.py`](../../plugins/alone/台风本地.py) | **1.0.0** | `台风本地`… | 仅本地绘制（气泡标注） | ★★ 要自定义图/对比时用 |

另：`_台风本地.py` 为旧备份（文件名以下划线开头，**不会被加载**），可忽略或删除。

---

## 怎么选？

### 只装一个（大多数情况）

**只上传 `台风合.py`**，重载 alone 即可。

- 活跃台风：尽量显示中央气象台官网路径产品图（与网站一致）
- 官网没有的（历史停编如「巴威」）：自动本地绘图，不会空白
- 指令就是大家熟悉的 `台风`、`台风查询 沙德尔`

### 需要「只要官方原图、没有就提示没有」

装 **`台风官网.py`**（可与合并版并存，指令不冲突）。

- 适合：只要官方出图、不要本地风格图
- 停编/未发布产品图会提示暂无，**不会**本地兜底

### 需要「永远本地画」或做对比

装 **`台风本地.py`**（指令带 `台风本地` 前缀，可与合并版并存）。

- 适合：调试气泡图、离线风格、或和官网图对比
- 例：`台风本地查询 沙德尔`

### 三个一起装？

可以。指令前缀不同，不会抢同一命令：

| 用途 | 发 |
|------|----|
| 日常查询 | `台风查询 沙德尔`（合） |
| 强制官网图 | `台风官网查询 沙德尔` |
| 强制本地图 | `台风本地查询 沙德尔` |

**不要**再放一个无前缀冲突的旧 `台风.py`（会与 `台风合.py` 抢指令）。

## 功能对比

| 能力 | 台风合 | 台风官网 | 台风本地 |
|------|--------|----------|----------|
| 列表 / 年份 / 查询 | ✅ | ✅（前缀官网） | ✅（前缀本地） |

| 本地路径绘图 | ✅ 兜底 | ❌ | ✅ |
| 聊天气泡尖端拉到点 | ✅（本地图时） | — | ✅（旧气泡逻辑，已修性能） |
| 活跃防御建议 | ✅ | ❌ | ❌ |
| 详情代码块排版 | ✅ | 普通文本 | 普通文本 |
| HTTP 复用会话 | ✅ | ✅ | ✅ |
| 列表/详情短缓存 | ✅ | ✅ | ✅ |
| 官网页并行抓取 | ✅ | ✅ | — |
| 停编跳过官网扫描 | ✅ | ✅ | — |

数据接口统一：`typhoon.nmc.cn` JSON；官网图另走 `www.nmc.cn/publish/typhoon/` + `image.nmc.cn`。

## 部署注意

1. 放到 `ElainaBot_v2/plugins/alone/` 后**重载 alone 插件**。
2. 依赖：`aiohttp`、`Pillow`（本地/合并绘图需要）。
3. 数据目录自动创建：`plugins/alone/data/`（各版库文件不同，互不覆盖）。
4. 图床：带图回复依赖框架的 `image_hosting` 模块。

## 本次共同修复（隐藏问题）

三版已对齐的修复点：

- 每次请求新建 `ClientSession` → **复用会话**，卸载时关闭
- 列表/详情无缓存 → **短 TTL 缓存**（约 60–90s）
- 空英文名 `'' in en` 误匹配 → 增加 `en` 存在判断
- 过短数字编号乱匹配 → 收紧规则（≥4 位后缀 / 两位序号）
- 「耗时 xxxms」在配图前就算完 → 改为 **`t0` 含配图**
- 官网 8 页串行 → **并行**；停编跳过；去掉「只剩一页就乱配图」兜底
- 本地绘图堵事件循环 → **`asyncio.to_thread`**；字体缓存

详见同目录 [`版本对比.md`](./版本对比.md)。
